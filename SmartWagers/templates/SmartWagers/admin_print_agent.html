Install on a teller PC
  1. Install the USB receipt printer driver in Windows.
  2. Set that printer as the Windows default printer.
  3. Unzip SmartWagers-PrintAgent.zip (for example to C:\SmartWagers\local_print_agent\).
  4. Double-click install_print_agent.bat. It verifies the bundled Python, shows the detected default printer, and adds Startup.
  5. Optional: create server.env from server.env.example, then run create_teller_shortcut.bat.
  6. Test: open http://127.0.0.1:8765/health on that PC.

Leave printer_name empty in config.json to always use the Windows default. Set it only if the receipt printer is not the default.
